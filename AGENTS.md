# Mandatory Development & Communication Protocol

This rule is strictly enforced on all interactions and coding tasks within this repository.

## 1. Upfront Pre-Task Disclosure (MANDATORY BEFORE ANY CODE EDITS)
Before writing or modifying any code (whether creating a feature, resolving a bug, refactoring, or updating configs), you MUST provide an upfront plan containing:
1. **Proposed Changes**: Exact list of files, functions, and components that will be added or modified.
2. **Why It Is Necessary**: Clear technical and business rationale explaining why each modification is required.
3. **Anticipated Architectural Impact**: How these changes interact with the existing architecture and dependent modules.

## 2. Post-Task Completion Report (MANDATORY AFTER TASK COMPLETION)
After completing every task and verifying tests/execution, you MUST provide a comprehensive report containing:
1. **Executive Summary**: What was accomplished.
2. **Detailed Breakdown of Changes**: Specific files modified, key logic updated, and error boundaries added.
3. **Impact on the Codebase**:
   - How data flow and agent interactions are affected.
   - Backward compatibility and dependencies.
   - Database, API, and storage implications.
4. **Verification & Test Output**: Concrete logs or test results confirming correctness.
